# 📜 Alternative Data Investment Terminal

A real-time Python and Streamlit-based pricing engine for retail market arbitrage. 

## 🚀 The Problem
Financial markets move in milliseconds, but valuable alternative web data is messy, unstructured, and constantly blocked by anti-bot systems. Traditional web scrapers break instantly when site HTML updates.

## 💡 The Solution
This terminal utilizes a self-healing data pipeline. By bypassing traditional scraping and triggering Bright Data's AI Scraper Studio via a direct REST API, the system seamlessly extracts live Indian Rupee (INR) pricing data, cleans it using Pandas, and visualizes the arbitrage opportunities in a real-time ledger.

## 🛠️ Tech Stack
* **Backend Pipeline:** Python, REST APIs (Requests)
* **Data Processing:** Pandas
* **Frontend UI:** Streamlit
* **Data Extraction:** Bright Data Web Scraper API
